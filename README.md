## Overview

VKBDevCfg provides deep firmware-level configuration for VKB Gladiator, Gunfighter, and MCG controllers including axis curves, button macros, LED profiles, and firmware update management.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **VKBDevCfg** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Axis Calibration** | Per-axis dead zone, saturation, and non-linearity calibration |
| **Button Macros** | Record multi-step button sequences with timing stored in firmware |
| **LED Control** | Configure per-button RGB LED colors and animation patterns |
| **Firmware Update** | Download and flash firmware updates directly from the utility |
